# 🎡 All in One Spinner

An interactive web-based spinner game with three game modes: Individual Game, Spinner Game, and Truth or Dare with spinner mechanics. Built with vanilla HTML5, CSS3, and JavaScript - no dependencies required!

## ✨ Features

### Three Game Modes
- **👤 Individual Game**: Spin among team members to select individuals from each team
- **🎯 Spinner Game**: Spin team names to determine which team plays next
- **🎭 Truth or Dare**: Party game with spinner-based player selection, 10 truth questions, and 10 dare challenges

### Core Features
- 🎯 Fair random selection algorithm
- 📊 Real-time winner database with statistics
- 💾 Save and load games with custom names using localStorage
- 🎨 Beautiful dark theme with vibrant neon colors
- ✨ Smooth 60fps animations
- 🎉 Confetti celebration effects
- 📱 Fully responsive (mobile, tablet, desktop)
- ⌨️ Keyboard shortcuts
- 🌐 Works completely offline
- 💾 Save up to 1000+ games

## 🚀 Quick Start

1. Download the three files: `index.html`, `style.css`, `script.js`
2. Place them in the same folder
3. Open `index.html` in your web browser
4. Select a game mode and start spinning!

## 🎮 How to Play

### Individual Game
```
1. Select "Individual Game" mode
2. Enter number of teams and members per team
3. Name your teams and members
4. Start the game
5. Click "SPIN" to select a team member
6. Winner is announced with confetti!
```

### Spinner Game
```
1. Select "Spinner Game" mode
2. Enter number of teams
3. Name your teams
4. Start the game
5. Spinner shows team names (not members)
6. Click "SPIN" to select which team plays next
```

### Truth or Dare
```
1. Select "Truth or Dare" mode
2. Enter number of players
3. Name each player
4. Start the game
5. Click "SPIN for Next Player"
6. Spinner rotates and selects a player
7. Player chooses "Truth" or "Dare"
8. Random question/challenge is displayed
9. Player completes the task
10. Click "Task Completed" for next player
```

## 🎓 How Spinners Work

The spinner uses a fair algorithm:
1. Generate 5-8 random full rotations
2. Add random offset (0-360 degrees)
3. Calculate segment angle based on participants
4. Determine selected participant mathematically
5. Apply smooth CSS animation (3 seconds)
6. Result is completely random and unbiased
